# XRP 网格交易策略

一个基于 Python 的 XRP/USDT 网格交易策略，支持历史回测和实盘模拟交易。

## 📋 功能特点

- **网格交易逻辑**：价格下跌分批买入，价格上涨分批卖出
- **动态网格调整**：当价格超出网格范围时自动重置网格中心
- **支持杠杆交易**：可配置杠杆倍数（默认 3 倍）
- **风险控制**：内置止损机制（默认总资产下跌 20% 止损）
- **双模式运行**：
  - 📊 **回测模式**：使用历史数据验证策略表现
  - 🔴 **实盘模拟**：连接币安 API 获取实时行情，本地模拟交易
- **断点续传**：交易状态保存至 JSON 文件，程序重启后自动恢复

## 📁 项目结构

## ⚙️ 策略参数

在 `grid_strategy.py` 中可以调整以下参数：

| 参数 | 默认值 | 说明 |
|------|--------|------|
| `GRID_LINES` | 20 | 网格数量 |
| `GRID_SPREAD` | 0.02 | 每个网格的间距（2%） |
| `INITIAL_CAPITAL` | 100 | 初始资金（USDT） |
| `POSITION_SIZE_PER_GRID` | 0.05 | 每格仓位占比（5%） |
| `LEVERAGE` | 3 | 杠杆倍数 |
| `STOP_LOSS_PCT` | 0.2 | 止损比例（20%） |
| `PROXY_URL` | None | 网络代理地址（国内用户需配置） |

## 🚀 使用方法

### 回测模式

```bash
python grid_strategy.py
```

运行后将输出：
- 总收益率
- 最大回撤
- 交易次数

### 实盘模拟模式

```bash
python grid_strategy.py live
```

实盘模拟会：
1. 连接币安交易所获取 XRP/USDT 实时价格
2. 在本地模拟账户执行网格交易
3. 实时显示当前价格、网格位置、持仓和权益
4. 自动保存交易状态到 `grid_state.json`

> ⚠️ **注意**：实盘模拟不会发送真实订单，仅作为策略验证工具。

## 🌐 代理设置（国内用户）

如果在国内无法访问币安 API，请在代码中配置代理：

```python
PROXY_URL = "http://127.0.0.1:7890"  # 根据你的代理端口修改
```

或者设置环境变量：

```bash
set HTTP_PROXY=http://127.0.0.1:7890
set HTTPS_PROXY=http://127.0.0.1:7890
```

## 📊 策略原理

```
        价格上涨 → 触发卖出（高抛）
            ↑
    [网格线 N+1] ────────────
            ↑
    [网格线 N  ] ←── 当前价格
            ↓
    [网格线 N-1] ────────────
            ↓
        价格下跌 → 触发买入（低吸）
```

- 网格策略适合 **震荡行情**
- 核心思想：**低买高卖**，在价格波动中获取差价收益
- 本策略为 **只做多** 模式，不会反向开空

## 📝 状态文件说明

```json

    "position": 10.22,          // 持仓数量

    "current_grid_index": 10,   // 当前网格索引
    "trades": [...]             // 最近交易记录
}
```
